# 卡兹克的技能

卡兹克自用的 6 个技能：写任务书、横纵分析、公众号长文、收尾整理、查 AI 资讯。

这是一组技能（共 6 个），装上后 agent 在需要时按技能说明去做。

## 包含的技能

- **aihot**：查询 AIHOT（aihot.news）的中文 AI 资讯。
- **hv-analysis**：横纵分析法（Horizontal-Vertical Analysis）深度研究Skill。
- **khazix-writer**：数字生命卡兹克（Khazix）的公众号长文写作skill。
- **leader**：把一句话的想法拆成 AI agent 能独立跑完的目标任务书。
- **neat-freak**：Knowledge and governance closeout: reconcile project docs, rule files (CLAUDE.md/AGENTS.md), authorized agent memory, and workspace residue with what the code and runtime actually do, so the next session or the next person starts from one current answer.
- **storage-analyzer**：macOS / Windows / Linux 只读存储分析助手（自动识别系统）。
