# Taste Skill

治 AI 做前端的通病：千篇一律的渐变、卡片和字体，先定设计方向再出页面。

这是一组技能（共 1 个），装上后 agent 在需要时按技能说明去做。

## 包含的技能

- **taste-skill**：tasteskill v2, the anti-slop frontend skill.
