# 宝玉的技能

宝玉的 21 个内容技能：配图、封面、信息图、翻译，发到公众号、微博和 X。

这是一组技能（共 21 个），装上后 agent 在需要时按技能说明去做。

## 包含的技能

- **baoyu-article-illustrator**：Analyzes article structure, identifies positions requiring visual aids, generates illustrations with Type × Style × Palette three-dimension approach.
- **baoyu-comic**：Knowledge comic creator supporting multiple art styles and tones.
- **baoyu-compress-image**：Compresses images to WebP (default) or PNG with automatic tool selection.
- **baoyu-cover-image**：Generates article cover images with 5 dimensions (type, palette, rendering, text, mood) combining 11 color palettes and 7 rendering styles.
- **baoyu-danger-gemini-web**：Generates images and text via reverse-engineered Gemini Web API.
- **baoyu-danger-x-to-markdown**：Converts X (Twitter) tweets and articles to markdown with YAML front matter.
- **baoyu-diagram**：Create professional diagrams with configurable dark/light theme via CSS custom properties.
- **baoyu-electron-extract**：Extracts resources and JavaScript from any installed Electron app (`.asar` bundle), restoring original sources from `.js.map` files when available or formatting minified code with Prettier otherwise.
- **baoyu-format-markdown**：Formats plain text or markdown files with frontmatter, titles, summaries, headings, bold, lists, and code blocks.
- **baoyu-image-gen**：AI image generation with OpenAI GPT Image 2.5, Azure OpenAI, Google, OpenRouter, DashScope, Z.AI GLM-Image, MiniMax, Jimeng, Seedream, Replicate and Agnes APIs.
- **baoyu-infographic**：Generate professional infographics with 21 layout types and 22 visual styles.
- **baoyu-markdown-to-html**：Converts Markdown to styled HTML with WeChat-compatible themes.
- **baoyu-post-to-wechat**：Posts content to WeChat Official Account (微信公众号) via API or Chrome CDP.
- **baoyu-post-to-weibo**：Posts content to Weibo (微博).
- **baoyu-post-to-x**：Posts content and articles to X (Twitter).
- **baoyu-slide-deck**：Generates professional slide deck images from content.
- **baoyu-translate**：This skill should be used when the user asks to "translate", "翻译", "精翻", "translate article", "translate to Chinese", "translate to English", "改成中文", "改成英文", "c…
- **baoyu-url-to-markdown**：Fetch any URL and convert to markdown using baoyu-fetch CLI (Chrome CDP with site-specific adapters).
- **baoyu-wechat-summary**：Summarizes WeChat group chat highlights into a structured digest using the local wx-cli binary (https://github.com/jackwener/wx-cli).
- **baoyu-xhs-images**：Generates infographic image card series with 12 visual styles, 8 layouts, and 3 color palettes.
- **baoyu-youtube-transcript**：Downloads YouTube video transcripts/subtitles and cover images by URL or video ID.
