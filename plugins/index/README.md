# 索引库

给 agent 一个 `symbol` 工具：查一个函数、类、接口、类型或常量**定义在哪个文件哪一行**。grep 一个名字会把每个调用处都列出来，索引只给定义它的那几行，最像的排在前面。

## 怎么用

装上就生效，不用配置。agent 第一次在某个项目里用 `symbol` 时建索引，同一个会话里接着用这一份；存下的索引新会话只信 10 分钟，过了就重建。

设置 › 索引库：

- 选一个项目，看它的符号数、已索引文件、索引大小和上次构建的时间。
- 「建立索引」「重建」：现在就重新扫一遍，开在这个项目里的会话下一次查时用新的。
- 「试搜」：输入至少两个字符，按名字搜；点一条用默认应用打开那个文件。

## 收什么

- 认得出声明写法的代码文件：TypeScript / JavaScript、Python、Go、Rust、Java、Kotlin、Swift、Ruby、PHP、C / C++、C#、Scala、Shell、SQL、Vue、Svelte。
- 在 git 仓库里只收 git 认为该看的文件（被忽略的不收）；`node_modules`、`dist`、`vendor` 这类目录即使提交了也跳过。
- 函数体里的局部变量不收；超过 800KB 的文件、二进制文件跳过；最多收 40000 个符号，到了上限会告诉 agent 后面的文件没收进来。

定义靠正则认，不做语法解析：能把 agent 带到对的文件和行，不保证每种写法都认得。认不出、或者定义在依赖里时，agent 会改用 grep。

索引存在插件的数据目录里，目录删掉以后（比如用完的工作树），下次加载时顺手清掉。
