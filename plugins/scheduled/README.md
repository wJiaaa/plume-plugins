# 定时任务

未查看的失败也会出现在侧栏铃的通知菜单中，点击即可打开定时任务页面。

把常做的事排成定时任务：每天早上审一遍未提交的改动，或者每小时跑一次测试、报告哪里失败了。

## 它做了什么

- **「定时任务」页面**：排在侧栏的去处里，一张卡片一个任务。名字、提示词、时间、开关都在卡片上直接改，改完就存。
- **两种时间**：每天固定时刻，或每隔多少分钟（最快一分钟一次）。打开的任务写着下次什么时候运行。
- **工作目录**：新任务记下建它时打开着的会话所在的项目（不在项目里时是会话的工作目录），每次运行都开在那里。
- **按时运行**：应用开着时每分钟看一次，到点的任务开一个新会话、把提示词作为第一句话发出去。每次都是新会话：一直往同一段对话里加，历史越长做的事越走样。上一次还没跑完时到点不再开一个，跑完以后只补一次；跑完是那个会话真闲下来：第一轮结束，它派出去的子 Agent、一次性的后台命令也都回来、做完了；它开着的开发服务器、监视和约好的唤醒不算，留在那个会话里接着跑。开出来的会话和你自己新建的一样，在侧栏里，能接着聊。
- **立即运行一次**：卡片上的 ▶，不管到没到点、开没开着。
- **运行状态和失败**：卡片上写着正在执行、等待你处理（批准一次工具调用，或回答它的提问、表单），「打开上次会话」，上次失败的原因（没开出会话，或者第一轮出错、原地打转、用满步数；你按了停止不算）。没人看见的失败在输入框上方说一句（「查看」带你到那张卡片），侧栏的「定时任务」那一行挂着数目；打开这一页就算看过。

## 用法

装上以后，点侧栏里的「定时任务」，再点「新建」。

> [!NOTE]
> 只在应用开着时运行：关着时错过的，下次打开后补跑一次。任务存在插件自己的数据目录里。
