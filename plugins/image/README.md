# 生图与画廊

让 agent 画图、改图，对话里边画边显示；侧栏多一个「画廊」，所有对话画过的图按天排开，点开一张能看到它是怎么一步步改出来的。

## 它做了什么

- **工具 `image_generate`**：按一段提示词出图，`count` 一次最多 4 张；`images` 给要改的图——`#1` 是对话里最新的那张图（人贴的附件、之前画的、截图都算），`#2` 是再往前一张，也可以给文件路径。项目外的文件先问人。出图最多等 5 分钟。
- **对话里的卡片**：画的时候按要的比例先占好位置，点阵在上面流动，角上一个估计的百分比，上面一行说进行到哪一步、连接不稳时说在重试；画好了在原地从模糊变清晰，上面一行是模型和尺寸。悬停有「编辑」（打开看图器直接标注，标完的副本进这个对话的输入框）和「下载」；点图用看图器看；右键可以在所属会话的文件标签打开、添加到聊天、复制、在系统文件管理器定位、下载副本。额度用完、密钥不能用这个模型、内容被拒时画成一张说明怎么处理的小卡。
- **侧栏「画廊」**：扫全部对话里画出来的图，按天排开；点开一张看大图、它的来历（从哪张改来、又改出了哪些），可以写一句要怎么改、送回它所在的对话，或跳回画它的那次调用。正在生成时按钮可停止当前轮，回车仍可排队；生成结果落盘后就地刷新，并在仍看着原图时打开改图结果。已有会话草稿会保留，改图要求追加进去等人自己发送。

## 用法

1. 在「扩展」里装上。
2. 设置 › 模型里，给供应商下能出图的模型（`gpt-image-1`、`gemini-3.1-flash-image` 这类）打开「生图模型」，可以点「测试」画一个小红点验证。
3. 有好几个生图模型时，在设置 › 智能体 ›「会话」里选默认用哪个；不选就用第一个。

一个生图模型都没有时，这个工具不出现在 agent 的工具表里。对话里点名一个生图模型（「用 gpt-image-1 画」），agent 会用那一个。

图存在应用数据目录的 `session-media/` 里，按内容命名，同一张只存一份；不写进项目目录，要放进项目时 agent 拿结果里的路径自己复制，那一步照常走写文件的审批。密钥只在 agent 进程里用，插件拿不到。
