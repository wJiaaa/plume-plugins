# 浏览器

在对话旁边开网页。人和 Agent 用的是同一页：Agent 打开、点按、输入、读页面，人在面板里看得见它的光标；人选中页面上的一块，连同要求放进输入框交给 Agent。

## 它做了什么

- **「浏览器」面板**：一个标签一页，后退、前进、刷新；地址栏也是搜索框，打的不是网址就交给设置里选的搜索引擎，打字时列出对得上的书签。最近看过的三个对话里的页面一直挂着，回来还在原处；更早的收起来省资源，回去时按原地址重新加载（Agent 正在用浏览器的对话不收）。标签可以弹到独立窗口，再收回来。
- **本机的 `.html`**：地址栏里打 `file://`、`~/` 或绝对路径，Agent 的 `browser_open` 还能给相对工作目录的路径。只给这一个文件（旁边的样式、脚本、图片加载不到），每次刷新现读磁盘。
- **菜单**：新标签页、关闭标签页、收藏和打开书签、检查元素、框选区域、开发者工具、缩放、视口尺寸（手机、平板、桌面或自己填）。
- **选取交给 Agent**：检查元素或框选区域以后，面板底下出一张卡，写一句想怎么改，选中那一块的地址、选择器、样式和 HTML 连同这句话接在输入框的草稿后面，截图作为附件挂上，看过再发。
- **回复里的链接**：右键回复里的网址可以「在内置浏览器打开」，`.html` 文件签悬停时多一个同样的按钮；设置里把「默认打开链接」选成内置浏览器，点网址就开在这里（Shift 点照旧交给系统浏览器）。
- **给 Agent 的工具**：
  - `browser_open`：打开网址或本机的 `.html`（先问一句，答过「以后不再问」的站点、文件不再问），把面板切到那一页，交回页面的文字和可操作的元素。
  - `browser_act`：在这一页上点按、输入、悬停、滚动、按键、执行脚本、等某段文字或元素出现、后退、前进、刷新。点按前等元素看得见、能点、没被挡住，被挡住时说出是谁挡的。
  - `browser_tabs`：列出、切换、关闭这个会话的标签。
  - `browser_viewport`：改缩放和视口尺寸，检查不同宽度下的排版。
  - `browser_screenshot`：截下这一页现在的样子交给 Agent 看（不问人）。
- **对话框**：Agent 操作期间页面弹出的 alert、confirm、离开页面提示由它应答（confirm 默认取消），答了什么写进工具结果；人自己浏览时照旧是系统对话框。
- **各会话分开**：每个会话有自己的标签，Agent 只看得到、操作得到自己会话的页；会话删了，它的网页一起关掉。
- **技能**：随包带一份 `browser` 技能，装了「技能」插件时 Agent 能读到怎么用这几个工具做页面检查和 E2E。

## 用法

装上以后，点标题栏右端的面板开关，在开始页里点「浏览器」，或者按 ⌘T（Mac 以外是 Ctrl+T）；或者让 Agent 打开一个网址。设置 › 浏览器里选回复里的网址默认开在哪、地址栏用哪家搜索、新页面的缩放，管理书签。

> [!NOTE]
> 只开 http 和 https 网址。网页跳去别的协议（唤起某个桌面客户端）时不跟过去，面板上给一个按钮交给系统浏览器。页面的 Cookie 和登录状态存在 Plume 自己的一份浏览数据里，和系统浏览器分开。
