# 会话互通

让对话读别的对话、互相发消息：在一个对话里定下的事，另一个对话不用你转述；要对方接手一件事、告诉它一个发现，直接发给它。

## 它做了什么

- **看得见谁**：侧栏里的对话，和这个对话在同一个项目里、目录相同或一个套着另一个，或者一个是从另一个开出来的（比如计划交给新会话执行）。子 Agent、侧边聊天不算，它们也用不了这几件工具。
- **名册**：互相开出来的一组会话（建议新会话、计划执行……一层层开出来的都算），每个成员的系统提示词里有一节「Linked sessions」，列出其他成员的称呼（开出它的一方起的短名，没有就是标题）和 id，写着谁开了谁。模型找自己开的会话只看它，不去搜。名册里不放状态：状态一变这一节就变，会断提示词缓存；要看谁在忙用 `list_sessions`。
- **`list_sessions`**：列出看得见的对话，每行是地址 `名字 [ref]`（ref 是 id 的前六位，改名以后照样认得）、id、短名、在干活 / 在等它的人 / 闲着、清单上正在做哪一步。带 `{"linked": true}` 只列名册里那一组。
- **`read_session`**：读一个对话此刻的完整记录（请求、回复、工具调用和结果），不打断它、不花它的钱；能翻页、能按关键字找。能读到的不问。
- **`send_message`**：给一个对话发一条消息。消息是单向的：对方闲着就为它开一轮，忙着就在下一步读到；它要回话就再发一条回来，这边不在原地等。工具那一行标着回执：排队中、已送达、已回复，没送到（被钩子拦下、对方删掉了）标红「未送达」，悬停说为什么。点了跳到对方。

## 边界

- 别的对话写来的话在对话里画成一行「来自 …」，点开读全文，旁边的箭头跳到那个对话。它们不是你说的话，不算你对任何操作的授权：对方请这边做的事照这边的权限来，被那边的人拒绝的事不会在这边代办。
- 防止几个对话原地来回：一条最多两万字（长的写成文件、给路径）；三十秒内一字不差的不重发；同一对之间发得太快的拦下。一个对话被别的对话的消息和开出来的会话的汇报连着叫起超过 10 轮、中间你一句话都没说，之后的就不再叫醒它，留到你下次开口时接在那句后面读（Plume 本体数，对话里提示一句）。
- 你停下一个对话时，攒着还没读的消息留着，不叫醒它，你下次开口时接在你那句后面读到。停下以后再发来的照常为它开一轮。
- 回执里的「未送达」只在应用开着时记得：重启以前发的、没读到的，之后一直显示「排队中」。

## 用法

装上就能用。从别的对话开出来的对话（计划模式的「在新会话里执行」、建议开出的新会话），来源还在侧栏里时系统提示词会告诉它来源在哪：拿不准来源里定下的意图时，先 `read_session` 读，读不出来再发一个短问题。也可以直接说：

> 告诉「重构登录 [3fa2c1]」那个对话，我们这边要改 `auth.ts`，让它先别动。
