# 终端

在对话旁边开一个真正的终端：shell 起在会话的工作目录里，颜色、提示符、Ctrl-C、编辑器和分页器这类全屏程序都照常用。

## 它做了什么

- **「终端」面板**：一个标签一个 shell，标题写着它前台在跑什么（「终端 1 · node」）。可以开好几个。
- **shell 比面板活得长**：换会话、去设置页或弹出独立窗口，接上的还是原来那个，正在跑的构建不会断；最近的输出按产生时的尺寸回放，再适配新窗口，避免光标控制序列覆盖旧画面；只有关掉标签或 shell 自己退出才结束它。应用或 agent 进程重启后恢复标签时会新建 shell，运行中的进程和回滚输出不会跨进程重启保留。
- **关标签前问一句**：前台还有程序在跑时先确认，停在提示符上的直接关。
- **查找**：⌘F（Mac 以外是 Ctrl+Shift+F）在回滚里查找，回车、Shift+回车前后跳。
- **右键复制、粘贴**：粘贴走括号粘贴，粘进来的命令不会直接执行。
- **点链接**：⌘ 点（Mac 以外 Ctrl 点）输出里的网址，开在回复里网址开的地方（装了内置浏览器并让它接手时开进内置浏览器），Shift 加点交给系统浏览器；⌘ 点 `src/app.ts:42` 这样的路径在文件面板里打开，只认会话目录里找得到的文件，相对路径拼不上时按结尾找唯一的一个。
- **拖文件进来**：从访达或文件面板拖进终端，打出加好引号的路径，末尾留一个空格，不会直接执行。
- **文件树里打开目录**：右键「在终端中打开」复用该会话已有的终端，没有才新开；终端准备好后切换到所选目录。
- **在终端运行**：回复里 shell 代码块（bash、sh、zsh 等）标题栏上的 ▶，去掉 `$ ` 提示符和注释行，在该会话的终端里执行（复用已有的，没有才新开）。

## 用法

装上以后，点标题栏右端的面板开关，在开始页里点「终端」；也可以直接按 ⌃`，焦点在终端里再按一次收起面板区。

> [!NOTE]
> 终端靠原生组件 node-pty 起 shell，它随插件一起装上。这台机器用不了它时，面板里会写明原因，Plume 的其他功能不受影响。
