# 下一步建议

agent 回完一轮后，替你想好下一句多半要说的话：输入框空着时显示成灰字，按 Tab 就填进去，看过再发。

## 它做了什么

- **让模型顺手写一句**：系统提示词里多一段说明，模型在一轮最后那条回复的末尾写一行 `:followup[你接下来多半会发的话]`。只在这条回复确实留下了明显的下一步时才写（没验过的那一步、给过的选项里你最可能选的那个、你要的东西里的下一项），大多数回复不写。
- **灰字**：最新那条回复写完了、你还没接话、也没在生成时，输入框空着就显示它；你开口以后、回复停在工具调用上时都没有。
- **回复里不显示**：标记那一行从回复正文和复制出去的字里拿掉，正在生成时写到一半的也不露出来；代码块和行内代码里的照原样显示。
- **只对主会话**：侧边聊天、子 Agent 这些子会话和插件自己的会话（比如 SSH 的运维助手）不加这段说明。

## 用法

装上即开。输入框空着时看到灰字，按 Tab 填进输入框，改一改或直接发送；不想要就照常打字，灰字自己消失。

- 不额外发请求：建议是模型写回复时顺带写的，不多花一次调用。
- 停用这个插件就关掉了：提示词里不再有这一段，灰字也不再出现。
