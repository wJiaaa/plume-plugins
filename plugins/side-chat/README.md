# 侧边聊天

在对话旁边另开一段聊天：问问主会话在做什么、为什么这样做、某段输出是什么意思，或者顺手让它做件小事。主对话里什么都不留，也不打断它正在跑的那一轮。

## 它做了什么

- **「侧边聊天」面板**：在面板区里开，⌥⌘S 也能打开。一个标签一段侧边聊天，能开好几个；标签上的字是第一问。重启恢复标签、弹出独立窗口时仍接回同一段记录。关掉标签就删掉那段，说过话的会先问一句。
- **看得到主会话**：每问一句，它都会拿到主会话上次之后的新内容；更早的、被截掉的，它用 `read_main_chat` 自己翻，包括工具调用和结果。
- **能做小事**：读文件、搜代码、改一处、跑条命令、查网页（装了网页插件的话）；会改动的照常弹审批卡，压在主输入框上方。大活它会建议你交给主会话。
- **交出去**：大活它用 `dispatch_task` 交出去。你说了「交给主会话」，它直接排进主会话的队列（和你在主输入框里排的是同一条队，主会话闲着就马上开跑，消息上标着「来自侧边聊天」）；没说的话只留一张卡片，你选交给主会话、开新会话（开在主会话的项目里），还是就在这里做。交过去的活照常走主会话的审批，不算你对任何操作的新授权。
- **控制主会话**：「让它停一下」「接着做」「它在忙吗」这类话它用 `control_main` 当场办，不排队；你明确取消旧目标时，停下的同时废掉旧的任务清单。
- **改了文件主会话会知道**：侧边聊天改过的文件，主会话下一轮开头收到一句说明（`<side-chat-changes>`），提醒它用之前先重读；只说一次，不打断主会话正在跑的那一轮。
- **`/btw 问题`**：在主输入框里敲，另开一段侧边聊天问这句话，面板跟着打开；只敲 `/btw` 就只打开面板。
- **在侧边聊天中打开**：主对话正忙时排着的消息，点它那一行的「更多 › 在侧边聊天中打开」，这句话（连同附件）拿到面板里最早那段侧边聊天去问，不占用正在跑的那一轮；还没有侧边聊天就新开一格。
- **划词提问**：在主对话里选一段话，点「在侧边聊天中提问」，引文挂到侧边聊天的输入框上，等你写好问题再发送。当前正在看的侧边聊天会继续使用；面板收起或正在看别的面板时另开一格。已有草稿、附件和引文保留，弹出、收回窗口也不会丢。

## 用法

装上就能用。侧边聊天挂在一个对话旁边，先在主对话里发一句话，再打开面板或者用 `/btw`：

> /btw 它刚才为什么不直接改 config.ts？

- 新的侧边聊天用设置 › 智能体 › 会话里「侧边聊天默认模型」选的模型，不选就用主对话的模型；已经开着的沿用它开时的模型。
- 主对话删掉时，它旁边的侧边聊天一起删掉。
