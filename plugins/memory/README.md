# 记忆

让 Plume 记住你的习惯和每个项目学到的东西，放进以后会话的提示词，不用每次重新交代。

## 它做了什么

- **用户记忆**：跟着你走的偏好（「习惯用 bun」「打包目标是 ES2024」），在设置里手动加，进每个会话的提示词。
- **项目记忆**：跟着仓库走，换个项目不带过去。两份来源：
  - agent 用 `learn` 工具刻意记下的教训（被你纠正过的做法、代码里看不出的约定、踩过的坑），存在 `learned.md`，可以手改；
  - 后台总结：开启后，你最近在用的那个项目空闲满 5 分钟（没有会话在跑）时，从 12 小时前到 30 天内结束的会话里提炼这个仓库的约定，合并进 `MEMORY.md`。同一个项目一天最多一次；只有完整回复才写入，截断或中断时保留旧记忆，候选会话留到下次重读；写了东西才弹一条提示。
- **每个会话冻结一份**：会话中途的 `learn`、后台总结或手改文件不会立即改变这份记忆；压缩、撤回、重新载入或换模型重建历史时重新读取。你在设置里删改的从下一次请求起生效。
- **每条记着最后一次进提示词的时间**：几个月没进过的，多半它说的东西已经不在了。

## 用法

装上就能用。设置 › 个性化里「全局指令」和「语气」之间多了「记忆」一节：

- 三个开关：用户记忆、项目记忆（关掉后既不读也不记，已有的留着；模型也看不到 `learn`）、自动沉淀项目记忆（默认关）。
- 加、删用户记忆；选一个项目，看它记住了什么，逐条删、丢掉后台总结的那一份，或者全部忘掉。

设置 › 智能体 › 会话里「记忆整理模型」选后台总结用哪个模型，不选就用新会话的默认模型。

> [!NOTE]
> 后台总结会把那些会话的内容（用户和助手说的话，不含工具结果，先去掉形如密钥的串）发给默认模型（或上面选的模型）。只总结开在项目里的会话。
> 数据都在插件自己的数据目录里；git 工作树里的会话算进主检出的那份记忆。
