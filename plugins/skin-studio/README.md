# 换肤工坊

用 12 色数据皮肤及可选细粒度 `tokens` 覆写改变 Plume 的外观。工坊提供背景与质感、系统外观切换和皮肤卡片画廊，也能让 AI 根据你的偏好设计、保存并应用新作品。

## 挑选配色

从输入框底部的调色盘按钮，或面板列表中的「换肤工坊」打开画廊。内置十二套配色：T3 Code 浅色与深色、Clawd 浅色与深色、薄荷清晨、蜜桃奶油、石墨、午夜莓果、深海青，以及晴空、薰衣草雾、青瓷三套色调皮肤；浅色七套，深色五套。T3 Code 两套复刻其默认的黑白与 zinc 灰阶、钴蓝交互色和细微分层；Clawd 两套除 12 色基础色板外，还经 `tokens` 补齐卡片/输入/浮层分层、半透明悬停与描边、状态色、代码块、行内代码、圆角与排版；其余八套的外圈（活动栏和顶上那一条）都比会话窗暗一档，两块分得开。纯白的浅色外观不单独做成皮肤，用「系统外观」一行的「浅色」，就是 Plume 自带的浅色配色。

色调皮肤只由一个色相和一个彩度推出：在 OKLCH 色彩空间里按固定的亮度档位算出 12 色，换色相时各档看起来一样亮。窗口外圈是一张从该色相斜着滑到相邻色相的粉彩渐变，正文区是近白的纸面。想要颗粒质感，在「全局背景与质感」里打开「磨砂」。

每张卡片是一幅缩略图，用作品的真实色值画出侧栏、主区、文字和强调色；正在使用的卡片右上角打勾。点击卡片会立即应用并保存选择，面板不会因此进入加载状态，下次启用插件时自动恢复；工具调用和其他窗口的更改也会同步，不必一直打开面板。

每套皮肤的 `base` 决定浅色或深色模式，不跟随系统在两套颜色之间切换。选择皮肤只临时接管配色与模式，不改写用户在外观页保存的偏好。点击「系统外观」一行右侧的「恢复原外观」或停用插件后，会撤下工坊皮肤并恢复原有偏好或其他已启用皮肤；字体、字号、代码排版仍由外观页负责。

「系统外观」一行的「跟随系统／浅色／深色」就是 设置 › 外观 里的三张主题卡片：点一下等于在外观页点同一张，会撤下正在用的工坊皮肤，改的是你的主题偏好，两边同步，停用工坊也不会变回去。配色、窗口毛玻璃都照外观页里你自己的设置。没用工坊皮肤时，这一行亮的就是外观页当前选的那张。

## 全局背景与质感

在工坊顶部的「全局背景与质感」卡片选择或拖入图片，可预览、清除；铺放方式（铺满／平铺）、五档浓度、背景效果、质感和显示位置（新对话、对话中）都是一排分段按钮。

质感选「磨砂」时，整个窗口（外圈和对话区）叠一层很淡的细噪点，深浅颗粒相互抵消，不会把底色拉灰。它和皮肤无关，换哪套皮肤、用不用默认配色都在；也不需要背景图片，有图片时叠在图片上，不受显示位置影响。

全局背景只在工坊里设置，设置 › 外观 不再有这一节。切换皮肤、恢复原配色或停用工坊不会删除它；需要清除时使用背景区的删除按钮。图片由宿主校验并存储。

皮肤还可在 JSON 的 `background` 里携带自己的会话背景。应用这套皮肤时优先显示皮肤图，切换或停用后恢复原全局背景；两者不是同一个槽位，皮肤图不会替换或删除全局图片。

## 保存、导入与复制

- **保存当前皮肤**：先应用一套工坊皮肤，再点画廊末尾的虚线卡片命名副本。每次都新增作品，不覆盖同名的旧作品。
- **导入别人分享的皮肤**：点「系统外观」一行右侧的剪贴板按钮，粘贴 JSON。工坊会即时校验并显示预览；点击「导入并应用」后，新作品同时保存和应用。
- **复制配色 JSON**：鼠标移到卡片上，名称右侧会出现复制按钮，只复制 `{ name, base, colors }`（有细粒度覆写、底纹或独立背景时分别带上 `tokens`、`backdrop`、`background`），不带内部 `id` 或 `builtin` 标记，可直接分享或再次导入。
- **删除作品**：自定义作品可以删除，内置配色不能删除。删除前会确认；正在使用的作品被删除后，恢复原外观。

## 12 色格式与校验

皮肤是声明式数据，不接受 CSS、脚本、路径或网络地址。JSON 包含名称 `name`、模式 `base`（`light` 或 `dark`）和以下完整的 `colors`：

| 键 | 含义 |
| --- | --- |
| `bgRoot` | 根背景 |
| `bgMain` | 主内容背景 |
| `bgSidebar` | 窄窗口浮出侧栏背景；停靠侧栏透明，与窗口外圈共用 `bgRoot` |
| `bgElevated` | 卡片、输入框和浮层背景 |
| `bgHover` | 悬停背景 |
| `bgActive` | 按下与激活背景 |
| `textPrimary` | 主要文字 |
| `textSecondary` | 次要文字 |
| `textTertiary` | 提示文字 |
| `accent` | 强调色 |
| `accentDim` | 强调底纹 |
| `border` | 分隔线和描边；浮层上的线和侧栏会话前的空心圈由 Plume 按文字色自动算，不用它 |

可选的 `tokens` 叠加在 12 色映射之上，按需细粒度覆写 Plume 公开的 `SkinToken`（如分别设置 `card`、`input`、`float`、半透明 `card-hover` / `elevated` / `line-float`、`window-tint`、`contrast`、`ok` / `danger` / `warning` / `on-accent` / `chart-*`、代码块与行内代码、语法高亮 `syntax-*`、圆角 `radius-*`、字体和字号）。颜色类 token 接受 `#RGB` / `#RRGGBB` / `#RRGGBBAA`、`transparent`、`currentColor`、`rgb()` / `hsl()` / `oklch()` / `oklab()` / `lab()` / `lch()` / `hwb()` / `color()`、`color-mix()` 以及 `var(--plume-*)`；不接受 `root-image`（外圈底纹走 `backdrop`）、`url()`、分号、花括号等不安全内容。用户在「设置 › 外观」手动设过的字体、字号和代码主题仍优先于皮肤。

可选的 `backdrop` 给窗口外圈铺一层渐变底纹：`{ "from": "#RRGGBB", "to": "#RRGGBB" }`，从 `from` 斜着过渡到 `to`。没有 `backdrop` 时外圈是 `bgRoot` 的实色。颗粒质感不属于皮肤，由「全局背景与质感」里的「磨砂」统一控制。

可选的 `background` 保存皮肤自己的会话背景：`image` 是 5 MB 以内的 PNG、JPEG、GIF 或 WebP Base64 data URL（所有自定义皮肤的背景合计不超过 20 MB）；`fit` 是 `cover` 或 `tile`；`effect` 是 `none`、`dither`、`ascii`、`halftone`、`scanlines`、`grid` 或 `haze`；`opacity` 为 0.05–0.65；`onNewChat`、`inChat` 控制两个显示位置。路径、HTTP(S)、SVG、CSS 和签名不匹配的伪图片都会被拒绝。

所有颜色必须为 `#RRGGBB`。名称不能为空，最多 80 个字符。主要文字、次要文字与全部六种背景（有底纹时再加 `from`、`to`）的对比度至少为 4.5:1，提示文字至少为 3:1。缺色、格式错误或对比度不足时，不会保存或应用。

## 让 AI 设计

点「系统外观」一行右侧的画笔按钮，工坊会把设计要求追加到这块面板所属会话的输入框，新对话则追加到当前输入框。已有草稿会保留，不会自动发送。可以补充喜欢的氛围、主色和深浅偏好，再自行发送。

提示词要求模型调用 `skin_studio_theme`，使用 `action="apply"` 并提供 `name`、`base` 和完整 `colors`（可选 `tokens`、`backdrop` 与 `background`），真正保存并应用，而不只是输出一段 JSON。也可以直接在对话中让模型列出皮肤、应用已有皮肤、保存副本、删除自定义作品或恢复原外观。工具的 `save` 只保存，`apply` 新配色时默认保存并应用；跟随系统、浅色、深色是你的应用设置，模型不会替你改。

## 数据与停用

自定义作品与当前选择保存在 Plume 的插件私有数据目录，和插件安装文件分开，不写入项目，也不覆盖用户的外观偏好。停用插件会取消各窗口的同步订阅并撤下皮肤，但保留作品库；重新启用后按保存的选择恢复。连接失败会在面板显示原因和重试按钮，不把未完成的操作显示成成功。
