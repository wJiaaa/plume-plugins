# 换肤工坊

用 Finch 风格的 12 色数据皮肤改变 Plume 的配色。工坊提供首页背景、系统外观切换和皮肤卡片画廊，也能让 AI 根据你的偏好设计、保存并应用新作品；不更改布局和字体。

## 挑选配色

从输入框底部的调色盘按钮，或面板列表中的「换肤工坊」打开画廊。内置八套配色：雪白、薄荷清晨、蜜桃奶油、石墨、午夜莓果、深海青，以及青春清爽的浅色、深色两套，浅色与深色各四套。

青春清爽已并入工坊，不再作为独立插件提供。浅色保留奶油背景、蓝黑文字与珊瑚强调色，深色保留蓝紫背景、浅紫文字与薄荷强调色；派生色转换为 12 色数据，按工坊规则分别选择深浅模式。

每张卡片是一幅缩略图，用作品的真实色值画出侧栏、主区、文字和强调色；正在使用的卡片右上角打勾。点击卡片会立即应用并保存选择，面板不会因此进入加载状态，下次启用插件时自动恢复；工具调用和其他窗口的更改也会同步，不必一直打开面板。

每套皮肤的 `base` 决定浅色或深色模式，不跟随系统在两套颜色之间切换。选择皮肤只临时接管配色与模式，不改写用户在外观页保存的偏好。点击「系统外观」一行右侧的「恢复原外观」或停用插件后，会撤下工坊皮肤并恢复原有偏好或其他已启用皮肤；字体、字号、代码排版仍由外观页负责。

「系统外观」一行直接使用 Plume 原生主题，提供「跟随系统／浅色／深色」。这是临时使用默认配色，不会清除之前保存的颜色；「恢复原外观」才是退出工坊管理，恢复那些偏好。默认模式也会保存，下次启用继续使用，但不会复制成固定的 12 色作品。

## 首页背景

在工坊顶部的「首页背景」卡片选择或拖入图片，可预览、清除；铺放方式（铺满／平铺）、五档浓度、背景效果和显示位置（新对话、对话中）都是一排分段按钮。

背景只在工坊里设置，设置 › 外观 不再有这一节。切换皮肤、恢复原配色或停用工坊不会删除背景；需要清除时使用背景区的删除按钮。图片由宿主校验并存储，不包含在配色 JSON 中。

## 保存、导入与复制

- **保存当前皮肤**：先应用一套工坊皮肤，再点画廊末尾的虚线卡片命名副本。每次都新增作品，不覆盖同名的旧作品。
- **导入别人分享的皮肤**：点「系统外观」一行右侧的剪贴板按钮，粘贴 JSON。工坊会即时校验并显示预览；点击「导入并应用」后，新作品同时保存和应用。
- **复制配色 JSON**：鼠标移到卡片上，名称右侧会出现复制按钮，只复制 `{ name, base, colors }`，不带内部 `id` 或 `builtin` 标记，可直接分享或再次导入。
- **删除作品**：自定义作品可以删除，内置配色不能删除。删除前会确认；正在使用的作品被删除后，恢复原外观。

## 12 色格式与校验

皮肤是配色数据，不是 CSS、脚本、路径或图片。JSON 包含名称 `name`、模式 `base`（`light` 或 `dark`）和以下完整的 `colors`：

| 键 | 含义 |
| --- | --- |
| `bgRoot` | 根背景 |
| `bgMain` | 主内容背景 |
| `bgSidebar` | 窄窗口浮出侧栏背景；停靠侧栏透明，与窗口外圈共用 `bgRoot` |
| `bgElevated` | 卡片、输入框和浮层背景 |
| `bgHover` | 悬停背景 |
| `bgActive` | 按下与激活背景 |
| `textPrimary` | 主要文字 |
| `textSecondary` | 次要文字 |
| `textTertiary` | 提示文字 |
| `accent` | 强调色 |
| `accentDim` | 强调底纹 |
| `border` | 描边 |

所有颜色必须为 `#RRGGBB`。名称不能为空，最多 80 个字符。主要文字、次要文字与全部六种背景的对比度至少为 4.5:1，提示文字至少为 3:1。缺色、格式错误或对比度不足时，不会保存或应用。

## 让 AI 设计

点「系统外观」一行右侧的画笔按钮，工坊会把设计要求追加到这块面板所属会话的输入框，新对话则追加到当前输入框。已有草稿会保留，不会自动发送。可以补充喜欢的氛围、主色和深浅偏好，再自行发送。

提示词要求模型调用 `skin_studio_theme`，使用 `action="apply"` 并提供 `name`、`base` 和完整 `colors`，真正保存并应用，而不只是输出一段 JSON。也可以直接在对话中让模型列出皮肤、应用已有皮肤、保存副本、删除自定义作品或恢复原外观。工具的 `save` 只保存，`apply` 新配色时默认保存并应用；`apply` 的 `id` 也可选 `default-system`、`default-light`、`default-dark`，使用对应模式的 Plume 默认配色。

## 数据与停用

自定义作品与当前选择保存在 Plume 的插件私有数据目录，和插件安装文件分开，不写入项目，也不覆盖用户的外观偏好。停用插件会取消各窗口的同步订阅并撤下皮肤，但保留作品库；重新启用后按保存的选择恢复。连接失败会在面板显示原因和重试按钮，不把未完成的操作显示成成功。
