# 计划模式

先看清楚、交一份计划，你批准之前不改任何文件。

## 它做了什么

- **开关**：输入框底下、权限旁边的计划模式开关，按对话记；新对话里拨了，第一句话发出去时跟着建出来的对话。`/plan` 也是这个开关，`/plan 要规划的事` 先进计划模式再把后半句发出去。
- **不改文件**：开着时 `write`、`edit` 直接拒绝；命令一律在只读沙箱里跑（和权限档无关，完全访问也一样），申请离开沙箱的拒绝。联网、别的插件的工具照常。这个对话派出去的子 Agent、侧边聊天也受同一道线。
- **交计划**：模型用 `submit_plan` 交一份 Markdown 计划，输入框上方弹出计划卡，完全访问也不替你批；对话里这一下读作「提交计划 标题」。
  - **接受**（⌘↵）：计划模式就地关掉，同一轮里接着做；请求批准档下还有「接受并开启自动模式」，先切到帮我批准再接着做。
  - **在新会话里执行**：计划连同评论存成文件，在同一个项目里开一个只带着这份计划的新会话去实施，这个对话就此停下，留着回答那边的提问；按钮旁的箭头给新会话挑模型，不挑用默认模型。装了会话互通插件（plume.sessions）时，新会话拿不准计划的意图会先读、再问这个对话。
  - **修改…**（Esc）：写下要怎么改，模型照着改完再交。
  - **拒绝**：这一轮停下，等你说下一步。
- **计划文件**：每次批准都把计划存进对话的临时目录（`plans/plan-<时刻>.md`），压缩以后模型照样能重读。
- **计划面板**：交计划时右栏自动打开一次，按 Markdown 读。等审批时划一段字就能留评论，评论按序号列在计划卡上：点「修订」连同补充的话一起发回去改；直接接受时评论作为「执行时注意」随计划交出去，计划不重写。批准过好几份时面板上能切换着看；环境卡片的「计划」一节逐份列出批准过的计划，点一行在面板里摊开那一份。
- **压缩后不丢**：上下文压缩把批准计划那一段概括掉时，批准的计划原样接在摘要后面。
- **提示词**：开着时系统提示词多一段计划模式的规矩；一轮查过东西却把方案写在正文里、没交计划时提醒一次。

## 用法

装上就能用：点输入框底下的计划模式开关，或者发 `/plan`。
