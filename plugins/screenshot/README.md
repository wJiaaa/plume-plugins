# 屏幕截图

按一下快捷键，当前屏幕定格，框出一块或点一下整个窗口，在上面画箭头、框、文字、马赛克，然后复制、下载或钉在桌面上。

## 它做了什么

- **全局快捷键**（默认 `Alt+A`）：Plume 不在前面也能截。指针所在的那块屏幕被拍下来，盖上一层浮层。
- **框选**：拖一个框；不拖、直接点一下，就是指针底下那个窗口（macOS）。框好后能拖边挪动、拖手柄调大小。
- **放大镜和取色**：框之前跟着指针的放大镜显示坐标和色值，按 ⌘C 把色值复制走。
- **标注**：框好就是标注工具条——画笔、箭头、矩形、文字、马赛克，能撤销。
- **完成**：图放进剪贴板（可在设置里关掉）；设了「截图保存位置」的话同时存一份文件。
- **下载**：存到「下载截图保存到」的目录，没设就是桌面。
- **置顶**：这块图变成一个浮在一切之上的小窗口，留在原地；拖它挪位置，Esc 或右上角的叉关掉。
- **输入框按钮**：设置里打开后，输入框左边常驻一个相机按钮。

## 用法

装上后在 **设置 → 截图** 里改快捷键、保存位置和完成后的动作；点「立即截屏」试一次。

> [!NOTE]
> macOS 第一次截图会弹出屏幕录制的授权，在系统设置里允许 Plume 之后再截一次。
