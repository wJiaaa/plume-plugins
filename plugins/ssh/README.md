# SSH

在 Plume 里管理常用服务器，在一页上开 SSH 终端、SFTP 文件和一个 AI 运维助手。助手可以请求在你连上的服务器上执行命令，每一条你都要先看过、可以改，然后才会运行。

## 它做了什么

侧栏里多一页「SSH 主机」，从左到右三栏：

- **主机库**（左边，可以收起）：
  - 新建、编辑、删除主机，加收藏、分组和标签；
  - 按名称、地址或标签模糊搜索，按收藏或分组筛选，列表按分组排开，组里收藏的在前、再按最近连接；
  - 点一台主机就在中间开一个终端标签连上它，已经有它的标签就切过去；「…」菜单里能再开一个连接。
- **终端**（中间）：一个标签对应一条连接，可以同时开好几个。
  - 第一次连接某台服务器时，要先和管理员给的指纹核对；以后指纹变了会直接拒绝连接。
  - 终端支持查找、右键复制和粘贴。离开这一页再回来，连接不会断，先回放最近的输出。
  - **资源占用**：打开顶上的开关后，每 5 秒读一次每条连接的 CPU、内存、磁盘和网速，显示在终端顶上的状态栏里。
  - **SFTP**：状态栏上的文件按钮在终端右边打开文件面板，从登录用户的家目录开始。双击文件夹进入，双击文件下载到「下载」文件夹（重名时自动加序号）；把本机文件拖进来上传到当前目录（同名会覆盖）；新建文件夹、重命名（F2）、删除（Delete，只能删文件和空文件夹）；传输可以随时取消。
  - **问 AI**：状态栏上的按钮或终端右键菜单，把选中的内容（没选中就是最近 200 行）交给右边的运维助手。发出前会去掉控制序列，遮住已保存的密码和常见的密钥。
- **AI 运维助手**（右边，固定）：和 Plume 的对话一样，能选模型、思考档位，能带附件。
  - 它能用这一页上连着的全部连接：`ssh_sessions` 看开着哪些，`ssh_run` 请求在其中一条上执行一条命令。这两个工具只在运维助手里有，别的对话里没有。
  - 每条命令的审批卡就出现在助手的输入框上方，写明在哪台服务器上执行（名称、账号地址、指纹）、为什么执行、超时多久。命令可以先改再运行；你改过时，助手会被告知实际执行的是改过的版本。
  - 「完全访问」「帮我批准」和「以后不再问」都不会替你批准这类命令。批准之后、发出之前还会再核对一次连接的身份，变了就不发。超时、断线或输出超限时，结果记为「未知」，不会自动重试。
  - 助手在等你批准而你不在这一页时，侧栏的「SSH 主机」那一行会挂上提醒，也会列进通知菜单。
  - 助手的对话不进侧栏的会话列表。头上「新开一段」开一段新的，「历史」里能回到说过的各段，或删掉现在这一段。
- **从 Excel 导入**：选一个 `.xlsx` 文件先预览，表头认得名称、地址、端口、账号、密码、分组，再勾选要导入的行。
  - 已存在的主机（地址、端口、账号都相同）、填写有误的行和带公式的行不能勾选。
  - 可以按表里的分组列自动建组。「下载模板」会把模板存到本机的「下载」文件夹。
- **批量命令**：顶上的按钮，勾选几条已连上的连接，把同一条命令在每条上各执行一次。
  - 执行前，确认框会列出每个目标的账号、地址、指纹和完整命令。确认之后目标有任何变化，都不会执行。
  - 不经过 AI，命令和结果不进入对话。

## 用法

1. 在侧栏打开「SSH 主机」，在左边新建一台主机或从 Excel 导入。
2. 点这台主机连上它，第一次连接时核对指纹。
3. 在右边对运维助手说出你的问题，比如「看看这台服务器为什么磁盘满了」。它每要执行一条命令，输入框上方就会出现审批卡。

> [!NOTE]
> 主机库（连同密码）经内置插件「密钥加密」（服务 `secrets`，AES-256-GCM）整份加密，存在本机的插件数据目录里；加密用的钥匙丢了、主机库解不开时，原文件挪到旁边（`hosts.enc.unreadable-…`），从空的主机库开始。密码只用于登录，界面上看不到，也不会交给模型。只支持密码登录。导入和下载的文件都放在系统的「下载」文件夹；上传只能把文件拖进 SFTP 面板，暂不支持传输文件夹。应用重启后连接不会恢复，要重新连。
