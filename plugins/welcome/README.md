# 每日一句

欢迎页的问候（早上好、下午好……）下面，每天换一句和写软件有关的话，代替默认的「要在某个项目里开发什么？」。

## 它做了什么

- **什么时候写**：每天第一次打开欢迎页时，在后台让默认模型写一句，带一个出处（人名或书名）。写好了在问候下面淡入，当天再打开都是这一句，不再调模型；换了界面语言会按新语言再写一句。
- **写什么**：和写软件、做工程、解决问题或专注做事有关，语气克制，不说教。可能是名人说过的话，也可能是模型自己编的，出处同样可能是编的，看着玩就好。
- **不重样**：记住最近 30 句，写新的时让模型避开。
- **写不出来时**：没配默认模型、20 秒内没回来、出错，或者写出来的不像一句话，这次就显示默认的那一行，下次打开欢迎页再试。

## 用法

装上就生效，不用设置。不想要了在插件市场里停用或卸载，欢迎页回到默认的那一行。

> [!NOTE]
> 每天会多调一次默认模型（每种界面语言一次），回复很短，用量不记在哪个会话名下。
