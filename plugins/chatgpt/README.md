# ChatGPT

用 ChatGPT 账号登录（Sign in with ChatGPT），把套餐里的额度给 Plume 用：账号能用的模型出现在设置 › 模型里的「ChatGPT」供应商下，不需要 API key。

## 用法

1. 在插件市场装上这个插件，打开它的详情页，在「设置」里点「用 ChatGPT 登录」。
2. 浏览器打开 OpenAI 的授权页，登录并允许 Plume 使用套餐额度。完成后回到 Plume。
3. 在设置 › 模型里选「ChatGPT」下的模型，或者在输入框的模型菜单里切过去。

用了多少额度、什么时候恢复，点设置里的「查看用量」到 ChatGPT 的设置里看。额度用完时 Plume 会停下这一轮并说明原因，不会一直重试；供应商会暂停，额度恢复后在模型设置里重新启用。

## 它做了什么

- **登录**：在本机 `127.0.0.1` 的随机端口上等浏览器回来，用 PKCE、state、nonce 走 OAuth，核对 OpenAI 签发的身份。第一次登录时 OpenAI 会为这台机器上的 Plume 注册一个应用，之后再登录沿用它。
- **凭据**：令牌经 Plume 加密后存在插件数据目录 `~/.plume/plugin-data/plume.chatgpt/connection.json`（只有本人可读写），只在 agent 进程里用，不进界面、日志和导出的供应商文件。`host.json` 里是这台机器的标识，不是密钥。
- **刷新**：令牌到期前自动换新的；网络出问题时稍后再试。OpenAI 明确拒绝时（比如你在 ChatGPT 里断开了 Plume）提示重新登录。
- **供应商**：「ChatGPT」供应商排在你自己的供应商后面，固定走 OpenAI 的 Responses API；连接地址、API 格式和凭据只由插件管理，在模型设置里只读。供应商能改名、启停、增删模型；花的是套餐额度，花销按 0 记。删除它等于断开。
- **断开**：吊销令牌并删掉本机的凭据。没能确认吊销时会提示你到 ChatGPT 设置里断开 Plume。

## 限制

- 这条通道只支持 OpenAI 列出的一部分请求参数和工具形状（见 OpenAI 的「Preview limitations」）；Plume 按它的规矩发请求，模型设置里给这些模型配的采样参数不会发出去。
- 生图模型不走这条通道。
- 一台机器同时只连一个 ChatGPT 账号。第一次登录时注册的应用绑定在当时选的工作区，之后再登录只能进那个工作区；要换账号或工作区，在设置的「换账号或工作区」里点「重新注册并登录」，新的登录成功后替换现在的连接，原来那个应用的令牌会被吊销。
- 套餐额度是否可用由 OpenAI 按账号、工作区和地区决定。
