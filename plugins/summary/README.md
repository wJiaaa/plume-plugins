# 会话摘要

在环境卡片里放一段话，说清这个会话在做什么、做到哪了、下一步是什么。隔了几小时回来，或者同时开着好几个会话，扫一眼就想得起来。

## 它做了什么

- **什么时候写**：一轮结束、静下来一分钟后，在后台写一次；一问一答连着来时不会每一轮都写。你说过至少三句话才写第一份，之后你每多说两句才再更新。只写侧栏里的会话：侧边聊天、子 Agent 这类子会话和插件自己的会话（比如 SSH 的运维助手）不写。
- **写什么**：只看你和 agent 说的话，再加上这段时间新建或改过的文件名；工具输出不送去。已经有一份时，只把之后的几条消息连同上一份送去，在上一份上改。一段话，最多两百来个字，语言和对话一致。
- **放在哪**：环境卡片里「摘要」那一节，在侧边聊天和压缩记录之间。还没写出来时这一节不占位；后台在写时画骨架；有了新消息、还没更新时标一句「这一轮结束后更新」；没写出来时留一个「重试」。不想看可以在卡片的「显示哪些内容」里关掉这一节。

## 用法

装上就能用。想换一个便宜点的模型来写，在设置 › 智能体 › 会话里选「会话摘要模型」；不选就用这个会话自己的模型。选的模型后来没了，退回会话自己的模型。

> [!NOTE]
> 每次更新都会在后台多调一次模型（送去的材料最多四千来个字），用量不记在会话名下，会话自己的用量不跟着变。
> 不想要这笔花销，在「扩展」里停用或卸载它；摘要存在插件自己的数据目录，删会话时一起删掉。
