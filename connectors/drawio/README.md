# draw.io

draw.io 官方（JGraph）出的。模型写出图的内容——draw.io XML、CSV 或 Mermaid——它在浏览器里用 draw.io 编辑器打开，你可以接着拖拽修改、导出成图片或 PDF。search_shapes 能在上万个图形里找到 AWS、Azure、Kubernetes、UML、BPMN 这些标准图标的准确样式；另外三个工具读写本地 .drawio 文件里的单页。

和让模型直接吐一段 Mermaid 相比，得到的是一张能继续编辑的正式图，而不是一段还要找地方渲染的文本。

图的数据放在网址 # 后面的片段里，浏览器不会把它发给 draw.io 的服务器。
