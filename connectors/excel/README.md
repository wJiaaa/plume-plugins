# Excel

社区项目，底层用 openpyxl 直接操作文件，所以机器上不需要装 Microsoft Excel。25 个工具：读写单元格、写公式并校验、设置数字格式和条件格式、合并单元格、插入删除行列、建工作表和复制重命名、建图表、建数据透视表和原生表格、读数据验证规则。

它只认 .xlsx 这类新格式，老的 .xls 要先转换。每次调用都要给出文件路径，它能读写当前用户能碰到的任何文件。

和 MarkItDown 的区别：那条只是把表格读成文本；这条能改文件本身，适合「按模板生成报表」「批量整理表格」这类要产出 xlsx 的活。
