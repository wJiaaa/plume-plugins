# Microsoft Learn

微软官方托管，不需要账号。三个工具：microsoft_docs_search 在 Microsoft Learn 里搜索，microsoft_docs_fetch 把整篇文档转成 Markdown 读回来，microsoft_code_sample_search 专门找官方代码示例。

它只读 learn.microsoft.com 上的一方文档，不会从来路不明的博客里拼答案。Azure、.NET、C#、PowerShell、Microsoft Graph 这些东西版本多、改得勤，查文档比靠模型的记忆可靠。

范围也就到这里：微软以外的技术它不管，那些用 Context7。
