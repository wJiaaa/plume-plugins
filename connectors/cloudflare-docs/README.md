# Cloudflare Docs

Cloudflare 官方托管，不需要账号。两个工具：search_cloudflare_documentation 在全部官方文档里搜索，migrate_pages_to_workers_guide 给出把 Pages 项目迁到 Workers 的步骤。

Cloudflare 的产品更新很勤，Workers 的绑定写法、wrangler 的配置、兼容性日期，模型记忆里的版本经常对不上。写 Workers 代码前让它先查一下，能少走不少弯路。

这个服务只读文档，不碰你的账户。管理 Workers、看日志、查 DNS 的是 Cloudflare 的另外几个服务，那些需要登录授权。
