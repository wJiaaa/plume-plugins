# DeepWiki

Cognition（做 Devin 的团队）托管的免费服务，不需要账号。三个工具：read_wiki_structure 看某个仓库的文档目录，read_wiki_contents 读具体章节，ask_wiki_question 直接对仓库提问。

内容来自 DeepWiki 事先为公开仓库生成的 wiki。它读过整个代码库，所以答得了「这个项目的插件是怎么加载的」这种要翻很多文件才能回答的问题。

和 Context7 的分工：Context7 取的是库的使用文档，回答「怎么用」；DeepWiki 讲的是仓库内部，回答「它是怎么做的」。只支持公开仓库；冷门仓库可能还没有生成过 wiki。
