# GitMCP

开源、免费、远程托管。这里配的是它的通用地址 gitmcp.io/docs，模型每次自己决定去读哪个仓库。五个工具：把库名对应到仓库，读仓库的 llms.txt、README 和文档，在文档里搜索，在代码里搜索，以及读文档里引用的链接。

它直接从 GitHub 读当前内容，不依赖预先生成的索引，所以冷门仓库、昨天刚发的版本也查得到。代价是它读到的就是仓库里写了的东西——文档写得少的项目，它也帮不上多少。

只想让它盯住一个仓库，把地址换成 gitmcp.io/<owner>/<repo>，模型就不会跑去读别的仓库。
