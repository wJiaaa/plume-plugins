# arXiv

社区项目。搜索支持分类、日期范围和排序；下载时优先取 HTML 版本，抽出来的正文比 PDF 干净。论文存在本地（默认 ~/.arxiv-mcp-server/papers），之后可以按目录逐节读、在全文里搜片段、对已下载的论文做语义检索，也能取原始 LaTeX 源码看公式。

另外几件事它也管：用 Semantic Scholar 查引用和被引，按 arXiv 元数据导出 BibTeX，订阅一个研究主题、之后只看新出的论文。

19 个工具，不需要任何密钥。想把论文存到别处，在参数里加 --storage-path 和目录。
